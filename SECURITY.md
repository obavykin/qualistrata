# Security Policy

QualiStrata is currently in early development.

## Reporting a vulnerability

If you discover a security issue, please do not open a public GitHub issue with sensitive details.

Instead, contact the maintainer privately.

## Sensitive data

The repository must not contain:

- credentials;
- tokens;
- private keys;
- customer names;
- internal hostnames;
- environment-specific secrets;
- proprietary product configuration;
- logs or reports containing sensitive information.

Example configuration files should use safe placeholder values only.
